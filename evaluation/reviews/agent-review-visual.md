# Agent review: visual quality

Agent review (reviewer sub-agent, not the builder). Build reviewed: `npm run build` on 2026-10-27, bundle `assets/index-DeWENuIB.js`, served on 127.0.0.1:4192. Headless Chromium with SwiftShader WebGL at 1440×900. No GPU, performance or Lighthouse runs were done (those belong to the orchestrator). All screenshots are in `evaluation/reviews/screenshots/`. Files 01–21 came from an earlier reviewer run that crashed; files 30–52 are from this run.

## Summary
Per preset, the scans look alike. Low has no AO and softer shadows, and Medium through Ultra add SMAA and AO (compare `10-low-relay-inspect.png` with `10-ultra-relay-inspect.png`). The two large visual defects do not depend on the preset. They come from a units bug in the hi-res magnifier models, and from Settings moving the camera.

## Per-preset notes
- **Low:** scans are legible and the painted relay number is readable without the magnifier at the hotspot zoom (`20-*`). There is no AO and shadows are softer.
- **Medium:** the same as High in practice in headless rendering, with SMAA edges. V1/V2/V3 reproduce.
- **High / Ultra:** AO grounds the objects (`10-ultra-*`). Both have the same V1/V2 defect.
- I found no z-fighting or broken base textures on any scan. The high-contrast and text-size settings change only the HTML layer, as designed.
